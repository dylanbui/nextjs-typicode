# 📚 Tổng Hợp Hệ Sinh Thái Thư Viện React / Next.js Phổ Biến

## 1. 🎨 UI Components & Styling

| Thư viện | Đặc điểm & Điểm mạnh | Trường hợp sử dụng tối ưu |
| :--- | :--- | :--- |
| **shadcn/ui** | Copy-paste components dựa trên Radix UI + Tailwind CSS, không bị vendor lock-in, toàn quyền kiểm soát mã nguồn. | Lựa chọn số 1 cho các ứng dụng Next.js hiện đại, SaaS, Dashboards. |
| **Tailwind CSS (v4)** | CSS utility-first thế hệ mới, tối ưu build speed, cấu hình trực tiếp qua CSS thay vì `tailwind.config.js`. | Định dạng giao diện nhanh, đồng nhất, dung lượng CSS tối thiểu. |
| **MUI (Material UI)** | Hệ thống component đồ sộ, hoàn chỉnh theo chuẩn Google Material Design. | Các dự án Enterprise, bảng quản trị nội bộ cần dựng nhanh không cần custom CSS nhiều. |
| **Mantine** | Bộ component phong phú, hỗ trợ SSR hoàn hảo, tích hợp sẵn hooks tiện ích. | Phù hợp cho cả web app tương tác cao và website SSR. |

## 2. ⚡ State Management & Data Fetching

| Thư viện | Đặc điểm & Điểm mạnh | Trường hợp sử dụng tối ưu |
| :--- | :--- | :--- |
| **ky** | HTTP Client dựa trên `fetch` tiêu chuẩn (tác giả Sindre Sorhus - cùng tác giả `got`), siêu nhẹ (~3KB), hỗ trợ Isomorphic (Server, Client, Edge), tích hợp sẵn **Auto Retries**, **Interceptors Hooks**, **Auto JSON** và **Multipart File Upload**. | Lựa chọn số 1 cho tầng Infrastructure HTTP Client trong Next.js App Router & Monorepo. |
| **TanStack Query (v5)** | Chuẩn mực quản lý **Server State**: Auto caching, Background fetching, Deduplication, Window Focus Refetching. | Bắt buộc cho mọi ứng dụng gọi REST API / GraphQL ở Client. |
| **Zustand** | Store quản lý **Client State** siêu nhẹ (~1KB), cú pháp hook trực quan, không cần Provider bọc ngoài. | Lưu giỏ hàng (Cart), đóng/mở Drawer/Modal, User UI Preferences. |
| **Jotai / Recoil** | Quản lý state theo mô hình nguyên tử (Atomic State), tối ưu re-render vi mô. | Ứng dụng đồ hoạ, Canvas, Spreadsheet, Interactive Dashboard. |
| **Redux Toolkit (RTK)** | Kiến trúc chặt chẽ, DevTools cực mạnh (Time-travel debugging). | Các dự án Enterprise siêu lớn, nhiều đội ngũ cùng phát triển. |
| **SWR** | Thư viện data fetching gọn nhẹ do chính Vercel phát triển theo cơ chế `stale-while-revalidate`. | Dự án Next.js cần cơ chế fetch/cache đơn giản, tối giản bundle size. |

## 3. 🔐 Authentication & Security

| Thư viện | Đặc điểm & Điểm mạnh | Trường hợp sử dụng tối ưu |
| :--- | :--- | :--- |
| **jose** | Thư viện mã hóa và ký số JWT/JWE chuẩn WebCrypto API, 0 dependency, siêu nhẹ (~0.02ms), chạy mượt 100% trên Edge Runtime (`middleware.ts`). | Lựa chọn số 1 cho Lưới lọc quyền (Permission Firewall) & Signed Session Claims tại Edge. |
| **Auth.js (NextAuth v5)** | Mã nguồn mở, hỗ trợ đa dạng OAuth providers, Email magic link, Credentials, tương thích sâu với App Router & Edge Runtime. | Tự chủ hoàn toàn hạ tầng xác thực, miễn phí. |
| **Clerk** | Dịch vụ Auth trọn gói, cung cấp sẵn UI components (Sign-in, User Profile, Org Switcher), bảo mật cấp cao. | Phát triển sản phẩm MVP/SaaS thần tốc, không tốn công dựng UI Auth. |
| **Better Auth** | Giải pháp xác thực thế hệ mới cho TypeScript/Next.js với độ linh hoạt cao và type-safety. | Dự án Next.js hiện đại cần giải pháp tự host nhẹ và an toàn. |
| **WorkOS** | Chuyên biệt cho doanh nghiệp với các tính năng Single Sign-On (SSO), SAML, Directory Sync (SCIM). | Ứng dụng B2B SaaS hướng tới khách hàng doanh nghiệp lớn. |

## 4. 🗄️ Database & ORM

| Thư viện | Đặc điểm & Điểm mạnh | Trường hợp sử dụng tối ưu |
| :--- | :--- | :--- |
| **Prisma ORM** | ORM chuẩn Type-safe hàng đầu cho TypeScript, schema trực quan (`schema.prisma`), hỗ trợ SQLite (local zero-config) và dễ dàng đổi sang MySQL, PostgreSQL, MariaDB chỉ bằng đổi biến môi trường. Có Prisma Studio quản trị dữ liệu trực quan. | Quản lý Stateful Session, lịch sử đăng nhập, người dùng nội bộ và nghiệp vụ doanh nghiệp. |
| **Drizzle ORM** | ORM thế hệ mới siêu nhẹ, SQL-like, native Edge Runtime. | Các dự án Edge-first cần tối ưu tối đa dung lượng bundle. |

## 6. 🧪 Testing & Quality Assurance

| :--- | :--- | :--- |
